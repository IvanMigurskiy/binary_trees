# TreeContainers

Этот репозиторий содержит исходные коды на C++ для реализации различных типов деревьев (Binary, AVL, Splay, Red-Black, 2-3-дерево). 

## Описание файлов

- main.cpp — пример использования, создание, добавление и удаление данных и индексов в деревьях различных типов.
- TreeRegistry.h — класс TreeRegistry, управляющий множеством деревьев, позволяет добавлять/удалять индексы и данные, искать элементы.
- BaseTree.h — базовый класс для всех деревьев, обеспечивает интерфейс и методы обхода.
- BinaryTree.h — реализация бинарного дерева поиска.
- AVLTree.h — реализация AVL-дерева, самобалансирующегося.
- RedBlackTree.h — реализация красно-черного дерева.
- SplayTree.h — реализация S-дерева.
- Tree23.h — реализация 2-3 дерева.
